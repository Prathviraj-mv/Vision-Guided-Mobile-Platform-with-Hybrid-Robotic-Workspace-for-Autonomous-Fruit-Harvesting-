# Project Images

This directory contains images and photos related to the autonomous fruit harvesting robot project.

## Contents

Add your images here:
- Robot assembly photos
- CAD renderings
- Test results
- Setup photos
- Detection examples

## Image Guidelines

- Use descriptive filenames (e.g., `robot_assembly_v1.jpg`)
- Include date/version in filename if needed
- Keep images under 5MB for git performance
- Use JPG for photos, PNG for diagrams
