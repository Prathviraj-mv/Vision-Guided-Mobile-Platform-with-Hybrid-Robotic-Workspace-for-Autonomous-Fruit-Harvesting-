# CAD Designs

This directory contains CAD files for the autonomous fruit harvesting robot.

## Contents

Add your CAD files here:
- SolidWorks assemblies (.sldasm, .sldprt)
- STL files for 3D printing
- DXF/DWG drawings
- Technical drawings

## Design Specifications

- **Arm Configuration**: RPR (Revolute-Prismatic-Revolute)
- **Link 1**: 20 cm
- **Link 2**: 10 cm
- **Rail Travel**: 30 cm vertical
- **Workspace**: X: 12-30 cm, Y: 0-30 cm

## Manufacturing Notes

- Material: Aluminum/PLA
- Tolerances: ±0.5 mm
- Assembly: M3/M4 hardware
